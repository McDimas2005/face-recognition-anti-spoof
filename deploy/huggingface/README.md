# Face Recognition Anti-Spoof API

FastAPI backend for the Face Attendance Platform portfolio demo.

This Space runs the backend API only. The frontend is deployed separately on Vercel, and durable data is stored in Neon PostgreSQL.

Current model/provider note: this deployment uses the demo-grade detector/embedder/liveness provider and is intended for portfolio demonstration, not production biometric security.
